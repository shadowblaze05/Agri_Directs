Import crop prices

Upload a CSV or Excel workbook (.xlsx) to add crops or update crop categories and prices. Every row is validated before anything is saved.

The file must contain only these columns: crop_name, category_name, price_unit, price. Enter kg for every price unit and a specific price (₱/kg) for each crop. Category may be blank; new categories in the file are added automatically. For an existing crop, a supplied category must match its current category. The range below applies to each crop's price from the file.

Download CSV template
A crop's allowed seller price is its CSV price plus or minus this range.

Import crop prices

Upload a CSV or Excel workbook (.xlsx) to add new crops or update crop categories. All rows and any selected shared price rule are validated before anything is saved.

The file must contain only these columns: crop_name, category_name, price_unit. Enter kg for every price unit. Category may be blank; new categories in the file are added automatically. For an existing crop, a supplied category must match its current category. If no shared rule is selected, the file adds crops/categories without changing existing prices; use the crop rule editor below to set rules individually.
